# لیست قیمت — حبوبات و خشکبار باقری

راهنمای کامل استفاده در انتهای پاسخ چت آمده است. خلاصه فایل‌ها:

- `index.html` — صفحه‌ای که مشتری می‌بیند.
- `admin.html` — پنل مدیریت شما (پشت یک کد ورود ساده، نه یک قفل امنیتی واقعی).
- `products.js` — تنها منبع اطلاعات محصولات؛ تغییر قیمت واقعی یعنی جایگزینی همین فایل در گیت‌هاب.
- `style.css`, `script.js` — ظاهر و توابع مشترک.
- `images/` — عکس لوگو (`logo.png`) و عکس محصولات را اینجا بگذارید.
