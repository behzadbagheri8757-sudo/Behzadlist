انتشار تغییرات برای مشتری

این صفحه (سایت GitHub Pages) استاتیک است، یعنی تغییراتی که بالا انجام دادید فقط روی همین گوشی ذخیره شده و مشتری آن را نمی‌بیند. برای اینکه واقعاً منتشر شود، باید فایل products.js در مخزن گیت‌هاب جایگزین شود:

  1. دکمه «کپی کد» یا «دانلود فایل» را بزنید.
  2. در گیت‌هاب، وارد فایل products.js شوید و روی مداد ویرایش (Edit) بزنید.
  3. محتوای قبلی را پاک کنید و کد جدید را جای‌گذاری (Paste) کنید.
  4. پایین صفحه روی Commit changes بزنید. حدود چند ثانیه تا یک دقیقه بعد، لینک مشتری به‌روز می‌شود.
